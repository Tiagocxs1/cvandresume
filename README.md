## Local Development
Simply open `index.html` in a browser, or serve with any static server:
```bash
npx serve .
# or
python -m http.server 8000
```

## Print to PDF
Open in browser → Print (Ctrl/Cmd+P) → Save as PDF → Margins: None

## Deploy
Push to `main` branch → GitHub Pages automatically deploys from root.
